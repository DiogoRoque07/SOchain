# SOchain

## Introduction

The SOchain project is part of the Operating Systems course at the Faculty of Sciences, University of Lisbon. The project aims to familiarize students with the challenges involved in using operating system resources. The project will be developed using the C programming language, Linux and POSIX APIs, and makefile programming.

The main goal of the project is to develop an application in C, called SOchain, to simulate a transaction system for a cryptocurrency token named SOT (SO Token). This application will allow a user, through the Main process, to control a set of wallets and perform SOT transactions between them. The system involves multiple cooperative processes representing three main entities: Main, Wallets, and Servers.

## System Overview

The SOchain system consists of three types of participants:

1. **Main**: Interacts with the user and allows them to request transactions on behalf of the wallets.
2. **Wallets**: Sign transactions where the wallet of origin is themselves.
3. **Servers**: Validate, process, and record transactions.

The interaction flow between the processes is as follows:
1. The user requests the creation of a transaction through the Main process.
2. The transaction is signed by the Wallet of origin.
3. The transaction is processed and recorded by the Servers.

## Project Structure

The project is divided into two phases. The first phase focuses on familiarizing students with C programming, makefile creation, process management, and memory allocation. The second phase will introduce synchronization between processes, signal handling, timers, and file operations.

### Directory Structure

The project should be organized as follows:

```plaintext
SOCHAIN/
  bin/
  inc/
  obj/
  src/
  makefile
```

- **bin/**: Contains the executable SOchain generated by the make command.
- **inc/**: Contains the header files (.h) with data structure definitions and function declarations.
- **obj/**: Contains the object files (.o) generated by the makefile.
- **src/**: Contains the source files (.c) with the developed code.

### Modules

The project consists of the following modules:

1. **Main (main.c/h)**: Manages other modules and interacts with the user.
2. **Process Management (process.c/h)**: Functions to create and destroy processes.
3. **Memory Management (memory.c/h)**: Functions for dynamic and shared memory creation and buffer operations.
4. **Wallet (wallet.c/h)**: Signs transactions and sends them to the buffer for Servers to process.
5. **Server (server.c/h)**: Validates, processes, and records transactions.

### Example Main Function

```c
int main(int argc, char *argv[]) {
    // Initialize data structures
    struct info_container* info = allocate_dynamic_memory(sizeof(struct info_container));
    struct buffers* buffs = allocate_dynamic_memory(sizeof(struct buffers));

    // Execute main code
    main_args(argc, argv, info);
    create_dynamic_memory_structs(info, buffs);
    create_shared_memory_structs(info, buffs);
    create_processes(info, buffs);
    user_interaction(info, buffs);

    // Release memory before terminating
    destroy_shared_memory_structs(info, buffs);
    destroy_dynamic_memory_structs(info, buffs);
    return 0;
}
```

## Usage

To run the SOchain executable, use the following command:

```sh
$ ./SOchain init_balance n_wallets n_servers buff_size max_txs
```

Where:
- `init_balance`: Initial amount of SOT assigned to each wallet.
- `n_wallets`: Total number of wallets in the system.
- `n_servers`: Number of servers responsible for processing transactions.
- `buff_size`: Maximum size of the buffers.
- `max_txs`: Maximum number of transactions the system can process.
